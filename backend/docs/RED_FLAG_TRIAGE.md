# 独立红旗症状预检（增强版）

该功能是调用大模型前的确定性安全层，不作诊断，也不表示未命中就是安全。用户消息保存时，
后端先执行本地规则；命中后返回 `triage.level = emergency`，前端显示固定紧急分流卡并跳过
大模型。流式接口还会再次拦截带紧急结果的最新消息，防止客户端绕过。

当前规则版本为 2026-09-10.2。结果记录规则版本与 deterministic_rules 评估方式，
并与原始消息一起加密保存。

## 首批规则

- 昏迷、叫不醒、意识丧失或明显意识异常。
- 呼吸困难、喘不上气、无法呼吸、窒息或停止呼吸。
- 胸痛、胸部疼痛、压迫或压榨样不适。
- 抽搐、全身严重痉挛。
- 大出血、血流不止、喷射状出血、大量呕血或咳血。
- 口角歪斜、一侧肢体无力、言语不清等脑卒中警示表现。
- 严重过敏表现同时伴呼吸道或吞咽异常。
- 溺水、触电、一氧化碳/煤气中毒、误食农药或服药过量。
- 呼吸或心搏骤停。
- 高处坠落、严重头部/颈部外伤、重物压伤、大面积烧伤和踩踏伤等严重创伤。
- 突发雷击样、爆炸样或异常剧烈头痛。
- 孕产期大量出血、抽搐或伴剧烈腹痛的危险表现。
- 已表达立即实施自伤、自杀或无法保证当前安全的危险。

规则会识别附近的“没有、否认、未出现、既往、已经缓解”等常见表达，并排除
“什么是胸痛”“如果出现抽搐怎么办”等明确的科普或假设语境，以降低明显误报。
这不是完整的中文医学否定或语义识别器，复杂句、方言、错别字、隐喻以及规则未覆盖的
急症仍可能误判或漏判。规则变更上线前应由急诊、精神卫生等专业人员审核并补回归测试。

## 固定分流

命中时提示立即拨打中国大陆急救电话 120，不建议用户独自驾车，要求听从急救调度员指导。
系统不自行给出用药、移动患者或专业抢救操作指令。预检结果包含规则编号、用户可读原因、
固定行动建议和检测时间，并使用项目字段密钥加密保存于 `messages.triage_ciphertext`。

迫在眉睫的自伤风险使用单独行动建议：无法保证安全时拨打 120 或 110，不要独处，并可在
保证当前安全的前提下拨打全国统一心理援助热线 12356。

## LangGraph 接入契约

app.safety.evaluate_triage(content) 始终返回 TriageAssessment，不会用 None 表示路由状态。
调用 as_langgraph_state() 后得到：

- triage_route：emergency 或 continue，可直接用于条件边。
- triage_rule_version：本次评估使用的规则版本。
- triage_rule_ids：命中的稳定规则编号。
- triage_result：紧急分流结构；未命中时为 None。

状态不包含原始症状文本或命中词片段。未来接入 LangGraph 时必须先运行该节点；
emergency 直接结束普通生成流程，只有 continue 可以进入追问、RAG 和模型节点。

  https://www.nhc.gov.cn/xcs/c100122/202405/f251e896a50a49ff8c632b4b3da93126/files/1734001844015_12363.pdf
- 国家卫生健康委员会《脑血管病防治指南》：中风 120 和 BEFAST 任一症状突然出现时应立即
  拨打 120。https://www.nhc.gov.cn/cms-search/downFiles/8b6cbb73fb2d49c2bab32f5f3325fafa.pdf
- 国家卫生健康委员会急诊科普：持续胸部闷痛、压迫感等高度疑似表现应立即拨打 120。
  https://www.nhc.gov.cn/xcs/c100122/201912/167c015db331483f9b51383db0e3638b.shtml
- American Heart Association：严重胸痛、呼吸困难、窒息、卒中表现、严重出血、意识丧失
  和严重过敏反应属于应立即呼叫急救系统的情况。
  https://www.heart.org/en/health-topics/house-calls/when-to-call-911
- 国家卫生健康委：全国统一心理援助热线为 12356，并推动其与 110、119、120 联动。
  https://www.nhc.gov.cn/yzygj/c100068/202412/49a1a65386cd4be582d4702fd0926ee8.shtml

## 验收重点

- 没有配置任何模型时，用户仍可提交消息并获得紧急分流卡。
- 命中后不得请求模型，也不得产生普通追问卡或常规科普回答。
- “没有胸痛”“以前胸痛”“胸痛已经缓解”等测试不得触发当前紧急分流。
- “什么是胸痛”“如果出现抽搐怎么办”等纯科普表达不得触发紧急分流。
- LangGraph 状态必须稳定返回 emergency/continue、规则版本和规则编号，且不包含原文。
- 预检结构保存为密文；消息历史恢复后仍显示相同分流卡。
