# 开发环境官方站点搜索原型

当用户询问明确病种、未触发红旗规则且本地 pgvector 返回的证据不覆盖这个病种时，
LangGraph 才进入 Tavily 搜索节点。问候、产品问答、只有症状而无法安全归类病种、
本地已有足够相关证据、以及紧急分流均不搜索。另有受控泛主题试点：
“甲状腺相关疾病有哪些”等概览问法映射为固定的“甲状腺疾病”主题；
特殊病种的治疗问题不会仅因包含“甲状腺疾病”几个字就触发泛主题搜索。
即使本地仅覆盖一个甲状腺疾病类别，也会尝试官网补搜。搜索失败不阻止原有 AI 回答；
**没有证据时不应把回答称为已核验医学资料。**

在 `backend/.env` 填 `TAVILY_API_KEY`，可选
`TAVILY_BASE_URL=https://api.tavily.com`，并保持
`APP_ENVIRONMENT=development`。重启后端后才会加载新环境变量。
该服务在 production 完全禁用，无需另建数据库表（复用知识库现有三张表）。
为避免真实用户医疗信息被发往搜索服务，程序只允许发送硬编码病种或
受控泛主题对应的固定搜索词；**绝不发送用户原始病情，
也不把仅去掉姓名的症状描述发给 Tavily**。需要新增病名时修改
`app/rag/web_search.py` 的 TOPICS；新增泛主题还需配置固定别名、证据词组和
搜索词，并增加安全测试。当前仅试点“甲状腺疾病”，不是全病种自动搜索。

搜索仅请求国家卫健委、疾控中心、药监局域名的中文结果，并在接收结果时
再次验证 HTTPS 和真实域名；最多扫描一次搜索的 8 个候选、明确病种取两条、
泛主题最多取三条标题和摘要均与主题相关的结果，不抓取网页全文。
长摘要优先截取含主题相关疾病词的相邻段落。泛主题会优先选择覆盖更多类别的结果，
但这种词组覆盖数不是医学准确率或完整性证明。
它们直接用于本轮回答的 prototype 引用；若用户查看来源，前端只开放
通过域名校验的官网链接并提示摘要未核对。搜索摘要保存为
`web_search_prototype` 来源的未审核文档/知识块，尝试用现有阿里云
Embedding 生成向量，后续在 development 中复用。原型摘要 30 天后不再
参与向量检索，可在下次相同主题问题中重新搜索。存储不成功时仍可使用
本轮合法来源的搜索摘要。引用的官网域名仅表示链接属于官方站点，
**不表示搜索摘要已核对原文、获得版权许可、经过医学审校，或答案可靠**。
不得将 `prototype` 自动升级为 `approved`。

本地来源的一般相关性阈值仍为 0.72；仅对来源可追溯、命中受控主题词的
联网原型摘要使用 0.60。它只是为了避免实际相似度约 0.66 的已缓存摘要
在第二次提问时被排除，不表示摘要的医学质量达标。

泛主题的“覆盖两类”只用于决定是否补搜，不是医学完整性认证。补搜后
会合并去重本地与官网摘要；若最终资料仅涉及一个类别，前端显示
“不能视为完整清单”。即使命中两类，也不能据此认定列举完整；
模型提示词要求避免把搜索摘要说成已核验网页全文或完整疾病列表。

流式咨询的 start 事件会返回 `retrieval.status`、
`retrieval.webSearchStatus` 和 `retrieval.webSearchErrorCode`。
页面在本地失败、官网超时、官网不可用、响应异常或没有相关摘要时给出不同的
“本轮无可核验参考资料”提示；普通聊天不显示。没有证据的回答不附来源卡。
提示仅保存在当前页面的运行内存中，刷新后不恢复；引用列表仍按已有
咨询历史逻辑保存。没有真正的文献审查，模型输出仍须谨慎看待。

这只是有限词表和简易相关性阈值的开发原型，不是疾病覆盖评估：
同义词、新病种、错别字和多病种可能漏检；余弦阈值不等于医学准确率。
实际涉及用户健康数据的上线前，应重新评估搜索供应商条款、版权、
数据隐私、人工审校与临床风险；目前不适合对外提供医疗用途。

确认数据库和本机 API Key 可用后，可运行一次受控真实服务检查：

```powershell
cd "D:\medicine and mannagement system\merchant_sales_cos-main\backend"
.\.venv\Scripts\python.exe -m app.rag.web_smoke
```

脚本只发送固定通用病名“甲状腺结节”，可能消耗 Tavily 搜索和阿里云
Embedding 额度；只输出搜索状态、向量化状态和二次复用结果，
不会输出密钥、健康详情或摘要正文，结束时回滚全部测试数据库写入。
如果本地知识本来已覆盖主题，联网步骤会跳过；如果官网没有合格结果，
二次复用步骤也会跳过。实际运行曾得到 `cached_prototype_reused=true`，
属于功能联通测试，不构成医学准确性验收。production 环境在 LangGraph
路由层直接跳过 Tavily，不会误称“已尝试官网搜索”。
