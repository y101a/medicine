# 多 Agent P0/P1 真实模型工程对照（2026-10-14）

## 口径

- 两道公开合成咨询题，使用已配置的 `qwen3.8-flash`；每题只检索一次、P0/P1 共用该轮检索结果。
- 实跑命令：`python -m app.ai.multi_agent_ab_benchmark --allow-paid`。脚本要求来源 `source_key` 全部为 `developer_prototype_knowledge`；否则跳过，不向模型发送。数据库会话末尾回滚；不创建用户、不保存聊天消息。输出只含指标，不含回答正文和密钥。
- P0 = 原回答生成；P1 = 一次回答规划 + 回答生成 + 一次删段式证据核查。两者都经过代码引用编号核验。耗时仅为各自生成阶段，不含共享检索时间；`model_calls_succeeded` 是成功完成的调用次数，不是精确费用或 token 账单。

两题均值：P0 约 7.4 秒、P1 约 21.2 秒，P1 为 P0 的约 2.9 倍；模型调用每题从 1 次增至 3 次。P1 最终文本明显缩短。由于两种模式各自独立生成，不能把长度差完全归因于核查删段；但 P1 草稿到最终段落数分别由 5→3、4→3，表明核查实际删减了内容。

## 结论与边界

- 这个小样本仅证明真实模型调用链可用、删段核查确实执行、引用编号未失效；**不证明 P1 的医学事实准确率高于 P0**。本轮没有保存逐句医学事实与原始来源对照，不能判断被删段落是否该删。
- P1 首字等待会明显变长，且模型费用约按调用次数上升，不能据此默认向全部用户开启。当前 `MULTI_AGENT_ENABLED=false` 默认值应保持；需要更多冻结题、独立证据核对标准和费用/延迟阈值后再决定是否扩大启用。
- 题集已用于开发和分析，不是盲测；公开原型来源未经专业医学审核。
