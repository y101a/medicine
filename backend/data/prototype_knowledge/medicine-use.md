# 合理用药

本文是个人开发使用的自编原型资料，内容不构成处方或个体用药建议。

## 普通感冒与抗菌药物

多数普通感冒与病毒感染有关，抗菌药物并不直接治疗病毒。不要因为鼻塞、流涕或咽痛
自行购买抗菌药物；是否需要使用应由医生结合病程、检查和个体情况判断。

## 阅读药品说明

使用药物前应核对名称、适应证、剂量、禁忌、不良反应和有效期。儿童、孕妇、老年人
以及肝肾功能异常者更需要专业指导，不要随意共用他人的处方药。

## 剩余药品与提前停药

上次治疗剩下的药、家里存放的旧处方药或抗菌药，不应仅凭“这次症状差不多”就自行继续吃。
相似症状的原因和适用药物可能不同，还要核对有效期、储存条件以及药品是否已经变质；不确定时
应把药品名称、包装和既往处方提供给医生或药师核对，也不要把剩余药品转给他人使用。

已经开始服用处方药或抗菌药物后，不要因为吃了两天、症状减轻或感觉好了就自行提前停药、
延长疗程或改变剂量，应按开具处方的医务人员说明使用。出现疑似不良反应、漏服或无法继续用药时，
及时联系医生或药师确认下一步；出现呼吸困难、意识异常等严重表现应立即寻求紧急帮助。
