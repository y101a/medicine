# 科学健身先评估再安排

本文是个人开发使用的自编原型资料，未经医学专业审核与版权审核，不能代替医生判断，也不用于诊断或治疗。

## 指南的框架

国家体育总局 2017 年发布的《全民健身指南》是国家层面首部体育健身活动指南，
主要内容框架包括：参加体育健身活动前的安全性评估、运动能力测试与评价、
个性化运动处方制定、一次体育健身活动方案，以及不同阶段的体育健身活动方案，
并介绍不同活动方式的健身效果与强度监控方法。

## 为什么先评估

这个框架传达的思路是：健身安排应该建立在对个人健康状况和运动能力的了解之上，
再决定练什么、练多少、怎么监控强度，而不是照搬别人的训练计划。

## 需要提醒的边界

这里只说明框架，不复制其中的处方模板，也不替代医生或运动处方师对个人的评估。
有心血管疾病、糖尿病、骨关节疾病或长期缺乏运动的人，开始锻炼前应先咨询医生。
