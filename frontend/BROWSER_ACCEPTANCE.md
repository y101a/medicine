# 浏览器人工验收清单

## 为什么需要它

单元测试跑在 jsdom 里，**没有布局引擎**，测不到真实排版、弹窗层级、滚动遮挡与定位降级。
本项目已经出现过「单元测试全绿但界面不可用」的情况——弹窗排版错乱、定位失败无提示、
接口异常时把原始 JSON 直接显示给用户。**单元测试通过不等于界面可用。**

动到界面之后，按本清单逐项截图核对。将来若引入 Playwright 自动化，以本清单为脚本骨架。

## 前置

- 后端已启动，前端已启动（`cd frontend && npm run dev`）
- 自动化基线已通过：`npx vue-tsc --noEmit -p tsconfig.app.json`、`npx vitest run`、`npm run build`
- 准备两个账号：一个正常账号；一个**已关闭采集**的账号，用于对照

- 截图**不要提交进仓库**，放本机临时目录即可

## 判定标准

不只是「能跑通」，还要看：

- 中文文案是否通顺、有没有暴露内部术语或原始报文
- 弹窗是否被遮挡、是否超出屏幕、长内容能否滚动
- 降级路径是否**有明确提示**，而不是静默失败或空白
- 窄屏下是否有横向滚动条、按钮是否被挤出可视区
